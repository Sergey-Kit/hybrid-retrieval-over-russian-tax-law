# Файлы замеров

Здесь лежат **только актуальные** результаты. Из них генерируются разделы README
командой `p3 render-results` — цифры в документации не переписываются руками.

| Файл | Что описывает |
|---|---|
| `test-full.json` | четыре конфигурации на объединённом корпусе (8198 чанков, 815 статей), held-out test: 331 достижимый запрос из 337 |
| `temporal-hybrid.json` | синтетический темпоральный тест на гибриде: 70 запросов «редакция на дату» |
| `negatives.json` | отделимость оценок на 331 позитиве и 45 негативах, три сигнала |
| `RESULTS.md`, `RESULTS.en.md` | сгенерированный раздел результатов, русский и английский |

## Чего здесь больше нет

Удалены замеры эпохи, когда в индексе была только часть первая: `test.json`,
`dev.json`, `report.json` (57 достижимых запросов из 337 вместо нынешних 331),
а также `temporal.json` (BM25-версия, заменённая гибридной) и `onehop-layer1.json`
(вклад one-hop, вошедший в `test-full.json` отдельным блоком).

Они остаются в истории git, но лежать рядом с актуальными им не следует: за эти
дни проект дважды заплатил прогонами по устаревшим артефактам, которые выглядели
как настоящие результаты и не вызывали никаких ошибок.
