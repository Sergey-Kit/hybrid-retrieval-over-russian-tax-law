# Как собрать данные (пошагово)

Нужно один раз выпустить трафик к двум государственным сайтам мимо VPN.
Весь сбор — около 50 запросов, полторы-две минуты.

---

## Вариант А: выключить VPN на пару минут

Пока VPN выключен, у Claude Code нет доступа к API — поэтому команду запускаете вы сами.

**1. Выключите Hiddify.**

**2. Проверьте сеть:**

```bash
PYTHONPATH=src python3 -m p3.cli netcheck
```

Должно написать `Среда годится для сбора`. Если пишет про страну FI — VPN ещё не выключился.

**3. Соберите всё одной командой:**

```bash
cd /home/claudeuser/projects/P3 && PYTHONPATH=src python3 -m p3.cli collect-all -v
```

Ожидаемый вывод в конце: `Готово. VPN можно включать обратно.`

**4. Включите Hiddify обратно** и напишите мне «готово».

Команду можно запускать сколько угодно раз: скачанное берётся из кэша, в сеть повторно
не ходит. Если что-то оборвалось — просто запустите снова.

## Вариант Б: split-tunnel в Hiddify (durable, пригодится на вехе 2)

Hiddify работает на sing-box, поэтому правила пишутся в формате `route.rules`,
а не в формате Xray `routing`.

Нужное правило — «эти домены идут напрямую»:

```json
{
  "route": {
    "rules": [
      {
        "domain_suffix": [
          "pravo.gov.ru",
          "nalog.gov.ru"
        ],
        "outbound": "direct"
      }
    ]
  }
}
```

Куда это положить в Hiddify Next: `Настройки` → `Config Options`, там есть раздел с
правилами маршрутизации. В части версий он называется `Routing rules` / `Правила
маршрутизации` и принимает строки вида `domain_suffix:pravo.gov.ru,direct`.

**Точное расположение и синтаксис отличаются между версиями Hiddify, и я это не проверял —**
у меня нет доступа к вашему клиенту. Ориентир для проверки один и тот же:

```bash
cd /home/claudeuser/projects/P3 && PYTHONPATH=src python3 -m p3.cli netcheck
```

При работающем VPN и правильном правиле команда должна показать
`pravo.gov.ru:443 открыт` и страну `RU`.

Важно: правило должно затрагивать **только** эти два домена. `api.anthropic.com` обязан
остаться в туннеле, иначе отвалится Claude Code.

## Почему нельзя просто собрать через VPN

`pravo.gov.ru` закрывает порт 443 для иностранных адресов, а ваш выход — Финляндия.
По открытому порту 80 он отвечает, и сбор технически пойдёт. Но полнота того, что он
отдаёт иностранному адресу, ничем не подтверждена, а ограничения на длинном обходе не
видны ни в кодах ответа, ни в логах. Получился бы правдоподобно-неполный корпус —
дефект, который проявится только когда поиск начнёт врать. Поэтому сбор заблокирован
в коде проверкой `p3.netcheck.preflight`.
