# Источники данных: что проверено и что из этого вышло

Документ существует ради **отрицательных результатов**. Проверка каждой гипотезы стоила от
получаса до нескольких часов, и без записи следующий человек (включая автора через полгода)
потратит это время заново.

Дата проверки — 2026-08-20.

---

## 1. Главный вывод

**Готового размеченного набора для этой задачи не существует.** Ни на GitHub, ни на
HuggingFace, ни у кого. `01-p3-p4-p5-spec` формулирует это так: «Не существует размеченного
набора „требование ФНС → правильный ответ" ни в открытом доступе, ни в закрытом. Это
одновременно наш моат и наше узкое место». Независимый поиск это подтвердил.

Отсюда следствие, которое стоит держать в голове при оценке трудоёмкости: собственный
пайплайн сбора — не издержка проекта, а его основной актив.

### JSON API ИПС

Реверс HTML с фреймами оказался обходным путём: у ИПС есть JSON API, карта которого
извлекается из SPA-бандла `ips.pravo.gov.ru/main.js`.

| Эндпоинт | Что даёт |
|---|---|
| `/api/ips/legislation/search.json` | поиск (POST) |
| `/api/ips/legislation/document_card.json` | карточка документа |
| `/api/ips/legislation/document_redactions.json` | **список редакций** |
| `/api/ips/legislation/document_redaction.json` | конкретная редакция |
| `/api/ips/legislation/documenttext`, `document_content` | текст |
| `/api/ips/legislation/document_refs.json` | **граф ссылок документа** |
| `document_changes.json`, `document_supplements.json`, `bpa-*.json` | изменения, приложения, справочники |

Два эндпоинта меняют веху 2 существенно:

* `document_redactions.json` снимает ловушку с перебором `rdk` — 96 из 249 значений в
  диапазоне не существуют и отдают заглушку с кодом 200;
* `document_refs.json` отдаёт граф ссылок **от самого источника**, тогда как `02-спека`
  предполагала строить `refs_out` разбором текста.

HTML-клиент сохраняется как независимый верификатор: совпадение перечня редакций,
полученного двумя разными путями, — дешёвая проверка корректности.

### Правовой статус текстов

По **ст. 1259 п. 6 ГК РФ** официальные документы государственных органов — законы, судебные
решения, иные материалы законодательного, административного и судебного характера — **не
являются объектами авторских прав**. Остаточный риск лежит не в текстах, а в праве
изготовителя базы данных (ст. 1334 ГК) и в условиях использования конкретного сайта; это
проверяется отдельно перед поставкой P5.

## 3. Оценочный набор: пары «запрос → нормы»

Ключевое требование к источнику — **не объём, а наличие эталона**. Вопросы без разметки
бесполезны, сколько бы их ни было.

| Источник | Разметка | Объём | Вердикт |
|---|---|---|---|
| **Решения по жалобам ФНС** | поле «Статьи НК РФ» от ведомства | 283 решения | **Используется** |
| **Письма ФНС, обязательные для применения** | поле `Теги:` со статьями | ~1700 писем | **Используется** |
| Письма Минфина (`minfin.gov.ru/.../Answers/`) | нет тегов | единицы на странице, PDF/DOCX | Слабо: мало, бинарные файлы, эталон пришлось бы извлекать из текста |
| **ФНС «Часто задаваемые вопросы»** | — | — | **Отвергнут:** из 10 ответов на НК ссылается **0**. Даже ответ про камеральную проверку не упоминает ст. 88. Язык там ровно продуктовый, но размечать нечем |
| `buhonline.ru` | — | — | Закрыт: «Контур: Доступ запрещён» |
| `klerk.ru` консультации | — | — | `robots.txt` разрешает `/consultations/?page=*`, но контент рендерится JavaScript — нужен headless-браузер. Эталона всё равно нет |

### Почему FAQ и форумы не спасают

Соблазн понятен: там живой язык бухгалтера, а у наших источников — формулировки ведомства.
Но пара для оценки состоит из **двух** частей, и вторая там отсутствует. Вопрос без
эталонной нормы нельзя ни засчитать, ни не засчитать.

Языковой разрыв закрывается иначе — синтетическим набором слоя 1, где одна и та же норма
спрашивается двумя способами: выдержкой из требования (с лексическим якорем) и живым
вопросом (без якоря). Эталон при этом известен по построению.

## 4. Что осталось непроверенным

* **Обзоры правовых позиций КС и ВС по налогообложению**, публикуемые ФНС ежеквартально:
  структура «фабула → нормы → вывод» выглядит подходящей, точный URL не найден (угаданные
  адреса дали 404).
* **Постановления Пленума ВС и обзоры судебной практики** — та же структура.
* **Реальные требования ФНС**, обезличенные. Лучшие данные из возможных: требование выносится
  по конкретной статье, и она в нём указана. Скрейпингом не добываются — только через людей.
